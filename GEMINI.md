# Decentralized Budget Tracker Instructions

- **Architecture:** Monolithic FastAPI app serving static Vanilla JS frontend.
- **Storage:** Local-first, browser IndexedDB only. No cloud database.
- **ML:** Python (Scikit-Learn) endpoints in `main.py` for classification and linear regression forecasting.
- **Style:** Minimal, clean, castle-grade Vanilla CSS.
- **YAGNI:** No frameworks, no external DBs, no unrequested abstractions.
